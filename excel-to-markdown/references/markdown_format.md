# Markdown 输出格式规范

> Step 3（读截图 + Markdown 组装）时参考。

## 标题层级

| 层级 | 用途 | 格式 |
|------|------|------|
| `# H1` | Sheet 名称（每 .md 仅 1 个） | `# Sheet: {SheetName}` |
| `## H2` | 一级功能模块 | `## 1. {模块名} (行范围)` |
| `### H3` | 二级子模块 | `### 1.1 {子模块名} (行范围)` |
| `#### H4` | 三级细项 | `#### 1.1.1 {细项名}` |

**划分原则**：大标题/章节编号 → H2，子编号 → H3，具体规则 → H4。只有两级时用 H2+H3。宁可多分层或多或少分层。

### 分隔线 `---`

**使用**：废弃与生效内容之间、不同主题模块之间、重要警告之前。
**不使用**：同模块连续内容之间、H3 子模块之间。


## 内容格式

### 表格

有明确表头 + 数据行格式一致 → Markdown 表格；否则保持文本树。

- 单元格文本与 data.md **一字不差**（剥离 `R{行号}| ` 前缀）
- 空单元格留空
- 合并单元格在左上角标记 `[合并N行×M列]`，其余留空

### UI 线框图（🟡疑似UI线框图）

当 data.md 标注 `🟡 疑似UI线框图` 时，该区域**可能**是策划用 Excel 边框画的简易界面示意而非数据表格。Agent MUST 结合截图（完整模式）或上下文语义（轻量模式）判断：

- **确认是 UI 线框图** → 用 **ASCII art 代码块** 重绘布局（见下方格式）
- **确认是数据表格** → 按正常表格格式输出，补充 `🤖[AI] 经截图确认为数据表格`

**输出格式**：

````markdown
🤖[AI] 以下区域为 Excel 边框绘制的 UI 线框示意图（非数据表格）。

### X.X 线框结构

```
┌──────────────────────────────────────────┐
│       [ Tab1 ]    [ Tab2 ]               │
│  ┌──────────┐                            │
│  │ 搜索 🔍  │                            │
│  └──────────┘                            │
│  列标题A      列标题B      列标题C        │
│  ──────────────────────────────────────  │
│  数据项1       值1          值2    [按钮] │
│  数据项2       值3          值4    [按钮] │
│  ──────────────────────────────────────  │
│  [操作1]     < 1/N >      [操作2]        │
│                                          │
│              提示文案                     │
│                                          │
│               [ 按钮A ]  [ 按钮B ]        │
└──────────────────────────────────────────┘
```
````

**绘制规则**：

| 元素 | ASCII 表示 | 示例 |
|------|-----------|------|
| 外框 | `┌─┐│└─┘` | `┌────────┐` |
| 内框/输入框 | `┌─┐│└─┘`（嵌套） | `┌──────┐` `│搜索🔍│` `└──────┘` |
| 按钮 | `[ 文本 ]` | `[ 确定 ]` `[ 取消 ]` |
| 分隔线 | `──────` | 条目之间 |
| 分页控件 | `< N/M >` | `< 1/3 >` |
| 标签页 | `[ Tab名 ]` 并排 | `[ 师父信息 ]  [ 徒弟信息 ]` |
**要点**：
- 代码块内的文本内容与 data.md **一字不差**，仅排版布局
- **MUST NOT** 在代码块内添加 `← 注释` 等行尾注释
- 代码块后用结构化列表补充各元素的交互细节，**补充的交互说明 MUST 加 `🤖[AI]` 前缀**（因为非原始策划文本）
- 颜色等富文本信息在代码块外用 `🤖[AI]` 标注

### 非表格文本

保持原始缩进格式，不强制转表格。

### 嵌入图片 & 精细截图引用

```markdown
📷 *嵌入图片 (A15:C20, 400x300)*

![描述](images/sheet_NN/detail_N.png)

🤖[AI] {详尽图片描述}
```

- 精细截图引用插在对应 `📷` 标记位置
- zone 合并时，首张图位置插引用，后续用 `（见上方 detail_N.png）`

### 截图视觉分析（完整模式 MUST 执行）

**MUST 读取每张截图**，按以下优先级转录：

1. **文字 MUST 逐字转录**：按钮文案、标题标签、提示说明、弹窗文案。**不要概括，要原文**
2. **数值 MUST 精确**：价格、数量、倍率、时间
3. **布局 SHOULD 描述**：界面分区、元素相对位置、交互元素
   - 界面分区（如 "左侧为资源栏，中央为棋盘，右侧为奖励面板"）
   - 元素相对位置（如 "底部两个按钮"、"右上角显示钻石数量"）
   - 交互元素（按钮、进度条、下拉框等）
4. **表格边界确认**：⚠️/🟡 区域对照截图确认，未检测到的表格记录行列范围

❌ `🤖[AI] 图中展示了抽奖活动界面`

✅ `🤖[AI] "星河漫步"活动界面：中央为爱心形棋盘路径。右侧奖励面板："x5 五倍奖励"、"x2 双倍奖励"、"获得花灵"。底部按钮："开启一次"、"开启五次"。顶部标题"星河漫步 I"，右上角钻石"10000"。...`

### 富文本

HTML 富文本标签 **MUST 原样保留**（`<del>` `<strong>` `<em>` `<u>` `<font color>` `<span style="background-color">`），不得转为 Markdown 语法。可在下方补充 `🤖[AI]` 语义说明。

### 超链接

`[显示文本](链接目标)` **MUST 原样保留**。下方补充 `🤖[AI]` 标注链接类型。

## 🤖[AI] 标注规则

| 类型 | 位置 | 示例 |
|------|------|------|
| Sheet 概览 | H1 后 | `🤖[AI] 概览：活动系统核心配置` |
| 颜色约定 | H1 后 | `🤖[AI] 本表颜色约定：红色=废弃, 黄底=待定` |
| 模块概述 | H2 后 | `🤖[AI] 3 个限时活动 + 1 条废弃配置` |
| 颜色说明 | 相关行下方 | `🤖[AI] 红色删除线表示已废弃` |
| 图片描述 | 📷 后 | `🤖[AI] {详尽转录}` |
| ⏳ 待定 | 相关行下方 | `🤖[AI] ⏳ 待定内容，需与策划确认` |
| 🗑️ 废弃 | 相关行下方 | `🤖[AI] 🗑️ 已废弃，无需实现` |
| ✨ 新增 | 相关行下方 | `🤖[AI] ✨ 新增/变更内容` |
| ⚠️ 约束 | 相关行下方 | `🤖[AI] ⚠️ 关键约束` |
| 🔗 引用 | 相关行下方 | `🤖[AI] 🔗 引用"奖励配置"表` |
| ❓ 疑问 | 相关行下方 | `🤖[AI] ❓ 待确认` |

- 每条独占一行，不在原始文本行内插入
- 无需补充时不添加
- **宁可多标注不遗漏**
